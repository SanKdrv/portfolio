cardgen

в проде

AI-помощник для карточек товаров КИП: FastAPI + Pydantic v2, любой OpenAI-совместимый API. Главное — детерминированная проверка ответа модели, чтобы она не выдумывала характеристики. 253 теста, покрытие 92%, Docker, CLI и веб-форма.

  • Python
  • FastAPI
  • LLM
  • Pydantic
  • Docker
Как устроено guard против выдуманных характеристик
  • Вход и факты Pydantic-валидация, нормализация чисел, единиц и кодов: 1,6 МПа и 1,6 бар — разные факты.
  • Генерация Промпт по JSON-схеме и любой OpenAI-совместимый API — без LangChain и SDK провайдеров, только chat/completions.
  • Guard Проверяет новые числа, пары «число + единица», коды (IP65, RS-485), полноту характеристик, отрицания и маркеры свойств.
  • Повтор и деградация Модель получает список замечаний и переписывает; после второй неудачи — безопасный шаблон с fallback_used.
  • Инфраструктура Docker, CLI, веб-форма, 253 теста и покрытие 92%, лимиты: 4 параллельные генерации и 60 запросов/мин на IP.
