О себе

Пишу бэкенд на Python и Go: FastAPI-сервисы, Go-микросервисы с gRPC/protobuf, PostgreSQL и ClickHouse, NATS JetStream, Docker и CI/CD. Отдельное направление — интеграции с LLM: вызовы моделей через API, RAG-пайплайны, проверка ответов модели на соответствие фактам. Ежедневно работаю через Claude Code и OpenCode Go.

Дипломная работа — RAG-система персонализированных рекомендаций (retrieval, эмбеддинги, векторный поиск).
